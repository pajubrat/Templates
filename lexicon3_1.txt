#
# Lexical reducancy rules
#
# format
# trigger > new features

D				=> 		COMP:N
Adv				=>		SPEC:Adv,ø λ:R α:V
P				=> 		COMP:D λ:R κ
C				=> 		COMP:T SPEC:D,ø
A				=> 		COMP:N,ø λ:L α:N
N				=> 		COMP:C,P,ø,C(rel) SPEC:A,ø
v				=>		V κ COMP:V SPEC:D wCOMP:V -ε
V/INTR			=> 		SPEC:D
V/TR			=>		COMP:D
Fin				=>		κ

T LANG:EN		=> 		COMP:V SPEC:D EPP PC:#X +wCOMP:V

T LANG:FI		=>  	COMP:V SPEC:D EPP PC:#X +wCOMP:V
PAR LANG:FI		=>		κ:v,P
NOM LANG:FI		=>		κ:Fin,ø
